# ⚔️ Ottoman Rage

> *"Sultanın emriyle yola çıktık. Kazıklı'nın başı ya boynunda kalacak ya da bizim elimizde."*

**Ottoman Rage**, Unreal Engine 5.7 ile geliştirilen, 15. yüzyıl Osmanlı dünyasını konu alan izometrik aksiyon RPG oyunudur.

## Hikaye

Yıl 1462. Sultan II. Mehmed, Vlad Dracul'u (Kazıklı Voyvoda) bertaraf etmek için gizli bir operasyon başlatır. Seçilmiş bir ajan **İstanbul'dan Bükreş'e** uzanan tehlikeli yolculukta 7 bölgeyi aşarak Vlad'ın karanlık ağını çözecektir.

## Oyun Özellikleri

- **6 Benzersiz Sınıf** — Yeniçeri, Abdal, Deli, Ozan, İmam, Sipahi
- **7 Bölge** — İstanbul'dan Bükreş'e, her biri farklı ekosistemde
- **Çeşitli Ortamlar** — Şehir, orman, bataklık, step, dağ, karanlık şato
- **6 Büyük Boss** + Final: Vlad Dracul (3 fazlı)
- **Derin RPG Sistemi** — Yetenek ağacı, ekipman, companion sistemi
- **Osmanlı & Balkan Mitolojisi** — Tarihsel figürler + Slav/Türk efsaneleri

## Sınıflar

| Sınıf | Tür | Güçlü Yön |
|-------|-----|-----------|
| Yeniçeri | Warrior | Tank, parry, karşı saldırı |
| Abdal | Druid | İyileştirme, DoT, debuff |
| Deli | Barbarian | Yüksek hasar, berserk modu |
| Ozan | Bard | Ekip buff/debuff, alan kontrolü |
| İmam | Wizard | Alan büyüsü, kutsal hasar |
| Sipahi | Ranger | Uzak mesafe, keşif, mobilite |

## Bölgeler

```
İstanbul (Şehir) → Edirne (Orman) → Filibe (Bataklık)
    → Sofya (Step) → Makedonya (Dağ) → Eflak → Bükreş (Final)
```
